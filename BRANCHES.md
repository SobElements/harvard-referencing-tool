# Git Branches Guide

## Main Branch (`main`)
This is the default stable branch. All changes are here and ready to use.

## Feature Branches

### `feature/auto-save-styles`
**Status:** Ready to merge (optional)  
**What it adds:** Auto-saving style customizations to localStorage

**Features included:**
- Style Editor changes are automatically saved to browser storage
- Custom styles apply across the entire site automatically
- No need to download or copy CSS
- "Reset to Default" button to clear customizations
- Updated help modal with new workflow

**For Sam:** If you like this feature, you can merge it into main. If you prefer the old copy/download workflow, you can stay on main.

---

## How to Use Branches (For Sam)

If you want to test the auto-save feature:
1. **In GitHub:** Go to the repository
2. **Switch branch:** Look for the branch selector (currently showing "main")
3. **Select:** `feature/auto-save-styles`
4. **Test it:** Try the Style Editor—changes should save automatically
5. **If you like it:** Contact your collaborator to merge it into main
6. **If you don't:** Just stay on main, no changes needed

---

## Why Separate Branches?

This approach lets you:
- Keep main stable with the current setup
- Try new features without affecting your main project
- Decide later if you want to adopt changes
- Keep a record of what was changed

It's a safe way to experiment! 🚀
