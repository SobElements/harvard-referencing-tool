Reference List Tutorial

Learn how to create and format comprehensive reference lists in Harvard style

What Goes in a Reference List

▼

Only include sources that you have cited in your text:

  • Every source mentioned in your in-text citations
  • Books, journal articles, websites, reports, etc.
  • All author types (individual, corporate, government)

Do not include:

  • Sources you read but didn't cite
  • General background reading
  • Personal communications (these are in-text only)

Note: If you consulted sources for background understanding but didn't cite them, you may create a separate "Bibliography" section for these additional sources.

You may not need to provide a general bibliography however, so it is worth double checking if this is required.

Basic Formatting Rules

▼

Alphabetical Order: List all sources alphabetically by author's surname (A-Z) or by title if no author.

Hanging Indent: The first line of each entry starts at the left margin, subsequent lines are indented by 0.5 inches (1.27 cm).

Spacing: Double-space the entire list

Multiple Works by Same Author: List chronologically (earliest year first)

No Author: Alphabetise by the first significant word of the title (ignore "The", "A", "An")

Mixed Source Types Example

▼

Complete Reference List Example:

Anderson, M., Thompson, K. and Williams, R. (2021). Digital transformation in modern educational institutions: A comprehensive study of student outcomes and teacher adaptation. Journal of Educational Technology Research, 28(4), 156-189.

Brown, A. S. (2020). Innovative teaching methods for the digital age: Integrating technology and traditional pedagogy in contemporary classrooms. Cambridge Academic Press.

Johnson, L. M. (2019). Climate change education and environmental awareness: Examining the effectiveness of sustainability programs in higher education institutions. Environmental Education Quarterly, 45(2), 78-95.

Smith, J. K. (2022, March 15). The future of remote learning technologies: How virtual classrooms are reshaping educational delivery and student engagement. Education Innovation Weekly. https://www.eduinnovation.com/remote-learning-technologies

Bibliography vs Reference List

▼

Reference list

  • Contains ONLY the sources cited in the text
  • Required for all academic work
  • Matches exactly with in-text citations

Bibliography (if required):

  • Contains ALL sources you consulted, even if not cited in the text
  • Includes backgroun reading
  • Usually only required if specifically requested
  • Appears after the reference list

Check with youre institution: Some prefer separate lists, others combine them. Most commonly, you'll only need a reference list.
